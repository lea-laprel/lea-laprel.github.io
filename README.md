# Les Démons de Léa Laprel — le jeu du lecteur

Le site du jeu, servi par GitHub Pages. Deux entrées : **« J'ai lu le
livre »**, pour qui vient de refermer le roman, et **« Code classe »**,
qui ouvre la version scolaire — extraits du roman et étude de la langue
— avec le code imprimé dans le livre.

Ce dépôt ne contient **que** le site : pas de code de fabrication, pas
d'outils, pas le texte du roman. L'atelier d'où il sort vit hors ligne,
sur la machine de l'auteur.

Les extraits affichés en classe sont volontairement courts : ils tiennent
sous **9 %** du roman, l'ebook étant en exclusivité KDP Select jusqu'au
13 janvier 2027. Les coupes sont signalées par « […] ».

Le code de la classe n'est écrit nulle part ici : seule son empreinte
figure dans `etapes.json`.
